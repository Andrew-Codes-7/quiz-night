# Quiz Night

A trivia game for a group: set up players or teams, pick a category, and play timed rounds.

## Features

- Players and teams, rounds and a countdown timer
- Categories including Flags, Country Shapes, Capitals, World History, Team Logos, Company Logos and General Knowledge
- Best scores remembered between games

## Tech

A single HTML file with vanilla JavaScript and CSS. No build step and no account; scores are saved in the browser with `localStorage`.

## Running it

Open `index.html` in a browser.
